# Unreal_Copy_Project
언리얼 엔진을 이용한 Fate/Samurai Remnant 모작 프로젝트입니다.<br/>
이 프로젝트는 플레이어블 캐릭터의 전투 시스템을 제작하였습니다.<br/>
Fate/Samurai Remnent의 스팀 이식 버전을 모델로 제작하였습니다.<br/>

구현 한 것<br/>
1. 이오리<br/>
2. 땅, 불의 형(공격 방식)<br/>
3. 세이버<br/>
4. 응격(반격)<br/>
5. 소비 아이템<br/>

구현 하지 못 한 것
1. 바람, 물, 공의 형(공격 방식)<br/>
2. 공명절기(합동기술)<br/>
3. 재료 아이템<br/>

키보드 설정<br/>
&nbsp;&nbsp;&nbsp;캐릭터/UI 이동 : W A S D<br/>
&nbsp;&nbsp;&nbsp;카메라 이동 :  Y G H B<br/>
&nbsp;&nbsp;&nbsp;약공격 : J<br/>
&nbsp;&nbsp;&nbsp;강공격 : I<br/>
&nbsp;&nbsp;&nbsp;비검(필살기) : L<br/>
&nbsp;&nbsp;&nbsp;이오리 스킬 사용 : Ctrl + V B N Space<br/>
&nbsp;&nbsp;&nbsp;서번트 스킬 사용 : F + V B N Space<br/>
&nbsp;&nbsp;&nbsp;서번트 교체 : F + Ctrl<br/>
&nbsp;&nbsp;&nbsp;소비 아이템창 : Shift<br/>
&nbsp;&nbsp;&nbsp;메뉴 : Tab<br/>
&nbsp;&nbsp;&nbsp;확인 : Enter<br/>
&nbsp;&nbsp;&nbsp;취소 : Backspace<br/>
키보드 조작이 조금 불편할 수 있습니다.<br/>
